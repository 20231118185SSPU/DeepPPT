Synthetic, non-sensitive, rebuildable PPTX fixtures for OfficeCLI integration testing.

| File | Slides | Content | Purpose |
|---|---|---|---|
| `native_revision_source.pptx` | 4 | Text shapes, table, chart, picture, grouped shapes | Native revision plan/apply/rollback testing |

## Rebuild

```bash
python skills/ppt-master/fixtures/officecli/rebuild_native_revision_source.py
python skills/ppt-master/fixtures/officecli/rebuild_docx_source.py
python skills/ppt-master/fixtures/officecli/rebuild_xlsx_source.py
```

Deterministic: repeated rebuilds produce byte-identical files (fixed zip
timestamps; the embedded chart workbook's core.xml timestamps and openpyxl's
core timestamps are neutralized; the openpyxl default font is reordered to the
Excel order OfficeCLI's schema validator expects).

## Properties

- **License**: MIT-0 (public-domain-equivalent; no attribution required)
- **Content**: All text/data is synthetic. No user, personal, or restricted content.
- **Chart**: Column clustered chart generated by python-pptx (known schema warnings on axId — non-functional, schema-only).
- **Picture**: Inline generated 400×225 PNG (solid color, no external references).
- **Stable IDs**: All shapes have deterministic shape IDs from python-pptx sequential assignment.

## OfficeCLI Verification

```bash
officecli validate native_revision_source.pptx --json
officecli view native_revision_source.pptx stats --json
officecli view native_revision_source.pptx outline --json
```

Expected: stats report 4 slides, 13 shapes, 1 chart, 1 picture; outline shows page titles.
Chart schema warnings are expected (python-pptx negative axId UInt32 — known issue, non-functional).
