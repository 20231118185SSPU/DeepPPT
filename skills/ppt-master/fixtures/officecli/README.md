|---|---|---|---|
| `native_revision_source.pptx` | 4 | Text shapes, table, chart, picture, grouped shapes | Native revision plan/apply/rollback testing |

## Rebuild

```bash
python skills/ppt-master/fixtures/officecli/rebuild_native_revision_source.py
```

## Properties

- **License**: MIT-0 (public-domain-equivalent; no attribution required)
- **Content**: All text/data is synthetic. No user, personal, or restricted content.
- **Chart**: Column clustered chart generated by python-pptx (known schema warnings on axId — non-functional, schema-only).
